## Leads worth chasing

- **ELK without a worker.** elkjs ships `lib/elk.bundled.js` next to `elk-worker.js`; if that bundle runs on the main thread it would make Rete's auto-arrange offline-safe — but it is EPL-2.0/GPL-3.0-or-later, a separate problem from `file://`.
- **BaklavaJS is the closest fit to the brief** and was not on the starting list: framework-agnostic core with a same-version first-party Vue 3 renderer, MIT, purpose-built for data-transformation node graphs.
- **X6 graph-ownership semantics** — passed every offline gate cleanly; open question is whether `Graph` insists on owning cell data.
- **JointJS core + `foreignObject`** — MPL-2.0, zero deps, no runtime assets, freshest release of the whole field. If HTML node bodies work, it clears every gate without touching JointJS+.
- Drawflow forks — check whether a maintained fork exists before writing it off entirely.

## What I looked for and could not find

- **Documented ownership-model quotes.** Package structure and dependency facts established, but no API-doc text retrieved stating whether Rete/X6/maxGraph/JointJS can act as a *view over an external model*. Every "owns graph data" cell above is **inference, not a cited quote — treat as unverified**.
- **GoJS licence specifics.** `gojs.net/latest/license.html` served a generic Northwoods template that never names GoJS; could not retrieve prices, watermark behaviour, or whether a runtime `licenseKey` must be set. Unverified.
- Whether Drawflow, X6 or JointJS inject a `<style>` tag versus requiring a linked stylesheet. X6's tarball contains zero CSS, which implies JS-injected styles, but the mechanism was not confirmed.
- AntV X6 maintenance signals beyond npm — no commit-frequency or issue-response evidence.
- `@joint/core` custom-HTML-node support — no doc retrieved confirming `foreignObject`/HTML element views. The single largest open question for the otherwise-cleanest candidate.
- **Any second source for the runtime-fetch findings** — those rest solely on the assistant's own tarball inspection.
