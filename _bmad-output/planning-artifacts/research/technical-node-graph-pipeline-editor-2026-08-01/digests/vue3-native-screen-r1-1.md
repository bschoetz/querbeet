## Leads worth chasing

- **`markRaw` as the escape hatch.** Vue Flow's own docs already prescribe `markRaw` for components. The open question — worth one focused experiment, not more searching — is whether `markRaw(frozenTable)` placed in `node.data` survives Vue Flow's ingestion untouched. If it does, Vue Flow's ownership problem collapses to a convention rather than a blocker.
- `docs/visual-editor/commands.md` in the baklavajs repo — Baklava has a command system, which is where undo/redo would live. Same for whether Baklava ships a minimap.
- **Auto-layout is shipped by neither.** Vue Flow's dependency list contains no layout engine and no `Worker` in its dist. The ecosystem answer is presumed dagre or elkjs, and **elkjs is the one to check hard** — an ELK worker build would be exactly the disqualifying lazy-load.
- `@vue-flow/background` at 21 months without a release. Zero runtime deps and a tiny surface, so vendoring the dotted background is likely cheaper than depending on it.
- **The six-month gap in Vue Flow's release stream** (1.48.2 on 2026-01-28, nothing since; last functional commit 2026-01-23) against 12 open issues. Low open-issue count with a stalled release stream reads as either "finished" or "maintainer stepped back".
- `@vue-flow/node-resizer` and `@vue-flow/node-toolbar` — not queried this run.

## What I looked for and could not find

- **Any retrospective account from a 6–12-month user of either library.** Only launch-register material surfaced — docs pages, a madewithvuejs listing, a DeepWiki auto-summary, a 2021-era CodeSandbox. The largest gap in the ecosystem-health picture; no verdict on real-world durability should lean on this run.
- **A definitive statement of whether Vue Flow proxies your array in place or copies it.** The state page describes internal state as reactive and offers `applyDefault: false` but never states the mechanism. The dist grep (0× `deep: true`) is suggestive, not conclusive. **This is the decisive question for this team and it is unresolved — settle it by experiment, not by documentation.**
- **Any evidence of a paid tier, licence key or relicensing event for either library.** MIT found consistently across five packages' `license` fields and LICENSE files, with GitHub Sponsors the only funding structure — but vueflow.dev's pricing/sponsor pages were not visited, so this is absence of evidence. Given that Vue Flow ships under a webkid GmbH copyright — the vendor whose React Flow line runs a Pro subscription — this deserves one direct check.
- **Undo/redo for Vue Flow.** Nothing in the docs pages read mentions it; could not confirm it is absent.
- **A fourth credible Vue-3-native candidate.** Two search passes returned Vue-2-era projects, vanilla-JS libraries and unrelated text editors. On this evidence the Vue-3-native field is genuinely two libraries deep, with VueWeave a distant and probably abandoned third.
