- (claim) ref=[32] status=verified class=failure-mode pub=2026-08 — NEW TRAP qualifying an R1 recommendation. R1's null-key sentinel substitution is safe only against a UNIQUE lookup. When both join inputs carry nulls — which a DAG makes easy, since two branches of one source inherit its nulls — every sentinel row matches every sentinel row and the output tracks the sentinel PAIR count almost exactly: 7k/14k/28k source rows produce 170,000 / 673,000 / 2,687,670 join rows against 167,000 / 667,000 / 2,668,000 sentinel pairs. Route out: exclude sentinel rows and re-attach, or give each side a distinct sentinel, or refuse the join; and warn in the Join Step UI when both inputs carry nulls in the key column.
