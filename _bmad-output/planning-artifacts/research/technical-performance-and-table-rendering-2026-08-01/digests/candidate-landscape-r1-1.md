# Digest — D1 / candidate field and screen — round 1, assistant 3

Brief: establish the credible 2026 field of Vue-3 virtualizers and data grids; current
version, licence, size, ESM/tree-shakeability, maintenance read over time; screen against
the hard gates (single file, no runtime fetch, file://, Vue 3, permissive licence).
Budget: 4 sources, 10 tool calls. Returned 2026-08-01.

### Findings

1. **`@tanstack/vue-virtual` is at 3.13.35, released 2026-07-28**, with 8 releases between 2026-06-02 and 2026-07-28 — an unusually high cadence indicating active maintenance. `{https://registry.npmjs.org/@tanstack/vue-virtual, npm registry (primary), 2026-07-28, accessed 2026-08-01, high, version}`
2. **TanStack Virtual is MIT, zero-runtime-dependency apart from its own `@tanstack/virtual-core@3.17.7`, declares `sideEffects: false`, ships both ESM (`dist/esm/index.js`) and CJS via an `exports` map, and peers `vue ^2.7.0 || ^3.0.0`** — Vue 3 is a first-class adapter package, not a community wrapper. `{same source, high, capability}`
3. **TanStack Virtual's real weight is the core, not the adapter: `virtual-core@3.17.7` measures 44.5 kB raw / 9.5 kB gzip, and the Vue adapter entry is a 1.8 kB / 0.6 kB gzip shim.** Figures self-computed (`gzip -9` over the npm dist files served by jsDelivr), not a published number. `{https://cdn.jsdelivr.net/npm/@tanstack/virtual-core@3.17.7/dist/esm/index.js, self-measured from npm artifact, accessed 2026-08-01, high, size}`
4. **`virtua` is at 0.50.0, released 2026-07-25, MIT, zero dependencies, `sideEffects: false`, with a dedicated `./vue` export subpath and peer `vue >=3.2`.** One codebase serving React/Vue/Solid/Svelte/Angular via separate subpath entries. 195 releases total. `{https://registry.npmjs.org/virtua, npm registry, 2026-07-25, accessed 2026-08-01, high, version}`
5. **virtua's Vue entry measures 25.8 kB raw / 6.3 kB gzip** (self-measured); bundlephobia independently reports the package root at 13.8 kB min / 5.9 kB gzip, 0 dependencies. The two agree closely, so the widely-quoted "~3 kB" marketing figure is optimistic by roughly 2x. `{bundlephobia + jsDelivr artifact, accessed 2026-08-01, high, size}`
6. **`vue-virtual-scroller` has finally shipped a stable 3.x: 3.0.4 on 2026-05-20**, MIT, zero dependencies, `type: module`, per-component `exports` subpaths, peer `vue ^3.3.0`. This ends its long stall on `2.0.0-beta.*`. `{https://registry.npmjs.org/vue-virtual-scroller, npm registry, 2026-05-20, accessed 2026-08-01, high, version}`
7. **vue-virtual-scroller declares `sideEffects: ["**/*.css"]` and ships a 1.5 kB stylesheet containing no `@font-face`, no `@import`, and no non-`data:` `url()`** — its CSS inlines cleanly with no runtime asset fetch. `{https://cdn.jsdelivr.net/npm/vue-virtual-scroller@3.0.4/dist/vue-virtual-scroller.css, self-inspected npm artifact, accessed 2026-08-01, high, capability}`
8. **`vue3-virtual-scroll-list` is dead: last release 0.2.1 on 2022-11-04, 6 releases ever, no `exports` map, no ESM `module` field.** `{https://registry.npmjs.org/vue3-virtual-scroll-list, npm registry, 2022-11-04, accessed 2026-08-01, high, ecosystem}`
9. **`@pdanpdan/virtual-scroll` 0.11.1 (2026-07-20) is a candidate not named in the brief and worth attention: MIT, zero deps, Vue-3-only peer, advertising list/table/grid modes with dynamic item sizing via ResizeObserver.** 73.5 kB raw / 19.4 kB gzip (self-measured). 18 releases total, still 0.x. `{https://registry.npmjs.org/@pdanpdan/virtual-scroll + https://github.com/pdanpdan/virtual-scroll, accessed 2026-08-01, high, version}`
10. **PrimeVue 5.0.0 (2026-07-15) is no longer MIT.** The `LICENSE.md` shipped inside the npm package is headed "PrimeUI License ... a family of **commercial** UI libraries by PrimeTek Informatics" and states: *"A valid license key is required to use this software. License verification is performed offline... A missing, invalid, or expired key may cause the software to display a license notice."* npm's metadata correspondingly reads `SEE LICENSE IN LICENSE.md`, not MIT. `{https://unpkg.com/primevue@5.0.0/LICENSE.md, PrimeTek (package artifact, primary), 2026-07-15, accessed 2026-08-01, high, licence}`
11. **PrimeVue 5's free "Community License" is eligibility-gated, not permissive**: under $1M annual revenue, fewer than 5 developers, fewer than 10 employees, under $3M outside funding, capped at 4 developers, and **requires annual renewal by re-confirming eligibility**. It also forbids reverse-engineering, decompiling, or removing the licence mechanism, and distributes the package compiled. `{same source, high, licence}`
12. **The relicence is corroborated independently and is not retroactive**: PrimeTek's own migration/announcement pages and a Hacker News thread ("PrimeVue no longer MIT, requires $799 license") describe v5 as the first release under the PrimeUI umbrella with a dual Community/Commercial model, all prior MIT versions staying MIT forever. Price discrepancy unresolved — vendor page reports $599/developer perpetual, HN thread title says $799. `{https://primeui.dev/nextchapter + https://news.ycombinator.com/item?id=48860682, ~2026-06/07, accessed 2026-08-01, medium, licence}`

15. **AG Grid Community 36.0.2 (2026-07-22) is MIT**, ships an ESM build with an `exports` map, but is enormous: bundlephobia reports **1251.8 kB min / 338.0 kB gzip**; the raw ESM bundle fetched is 2.21 MB. `{https://registry.npmjs.org/ag-grid-community + bundlephobia, accessed 2026-08-01, high, size}`

### Leads worth chasing

- **The PrimeVue relicence is the headline result and it reaches further than PrimeVue.** The same PrimeUI umbrella covers PrimeNG and PrimeReact. Also unresolved: **$599 vs $799 per developer** — vendor page and HN thread disagree; and whether a "missing key" merely prints a console notice or renders a visible watermark, which for a shipped single-file artifact is the difference between annoying and disqualifying.
- **RevoGrid's Stencil output is the one real unknown among the finalists.** Stencil can emit either a lazy-loader build (which `import()`s component chunks at runtime — fatal for a single inlined `file://` HTML) or a `dist-custom-elements` build (fine). `@revolist/vue3-datagrid` ships only a 43 kB wrapper and defers everything to `@revolist/revogrid`; which output mode that package uses was not inspected. **Verify before shortlisting it.**
- **`@pdanpdan/virtual-scroll` is the find worth a second look**: the only headless candidate shipping a purpose-built *table* mode with dynamic sizing, at ~19 kB. Against that: 0.x, 18 releases, repo is one person's name — a textbook bus-factor exposure.
- **A registry-date anomaly not explained**: npm's `time` map for `vue-virtual-scroller` dates `2.0.0-beta.10` to 2026-03-12 and `2.0.0` to 2026-03-31, conflicting with that package's long-known multi-year beta stall. Either the 3.x line was published on a compressed timeline this spring, or the queried mirror has rewritten timestamps. Confirm against the GitHub releases page before trusting the cadence read for this one package.
- Tabulator has no first-party Vue 3 binding — the integration cost is yours to own; third-party wrappers were not screened.

### What I looked for and could not find

- **All GitHub API calls returned empty** (`api.github.com` yielded null bodies for every repo — blocked or rate-limited in this environment). So there is **no direct evidence** on: star counts, commit cadence, issue-tracker responsiveness, open-vs-closed issue ratios, or contributor distribution. Maintenance claims are inferred **entirely from npm release timestamps**, which shows liveness but says nothing about whether issues get answered. The bus-factor question is therefore **unanswered** for every candidate except by weak proxy (personal account for virtua, vue-virtual-scroller, @pdanpdan/virtual-scroll; corporate/foundation-backed for AG Grid, TanStack, PrimeTek).
- **Bundlephobia returned errors for `@tanstack/vue-virtual`, `tabulator-tables`, `vue-virtual-scroller` and `@pdanpdan/virtual-scroll`** (4 of 7 queries failed). Substituted own `gzip -9` measurements of published dist files — a defensible primary measurement but **not** the same as a bundler's tree-shaken output. Treat every size figure as an upper bound with a known method, not a published number.
- **vue-virtual-scroller's actual gzip size is not established.** Its entry point is a 1.8 kB re-export barrel and components live in separate chunks across a 450 kB unpacked tree; measuring it properly needs a real bundle.
- **No candidate was tested from `file://`.** Every offline-safety claim is static analysis of shipped artifacts (grep for `new Worker`, `fetch(`, `@import`, `@font-face`, non-`data:` `url()`), not observed behaviour. Dynamic `import()` of code-split chunks — the most likely `file://` failure mode — was only checked for Tabulator (zero occurrences); **not checked for RevoGrid, AG Grid, or PrimeVue**.
- **No performance evidence at all.** Nothing here speaks to which of these holds 60 fps at 100k x 50, or their memory profile. The finalist set was chosen on licence, size and liveness — not on measured throughput.
- **The hand-roll option was not costed.** Screening the library field says nothing about whether a ~10 kB dependency beats 200 lines of own windowing code.
