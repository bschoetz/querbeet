# D4 — Ecosystem health, maturity, five-year regret risk

Scope: Vue 3 (`vue`, `vuejs/core`) vs Alpine.js (`alpinejs`, `alpinejs/alpine`). Accessed 2026-08-01.
Primary sources used: npm registry metadata, npm downloads API, GitHub REST/search API, raw repository files, one Vue release blog post, one Alpine PR page. 8 sources, 10 tool calls — budget spent.

## Leads

- **Watch alpinejs/alpine#4861.** It is approved by a collaborator and awaiting merge; if it lands, Alpine's reactivity core jumps from 2021 to 2026 in one step. Re-check its state before finalising any conclusion that depends on Alpine's reactivity being stale. It also implicitly answers "does Alpine accept structural contributions from outside": yes, reviewed within 6 days.
- **Vue 3.6 / vapor mode** has been in pre-release for an unusually long stretch (alpha.7 → beta.17 → rc.2, with 3.5.x carrying stable for ~2 years). Someone should assess whether 3.6 is a migration event or a drop-in; it bears on "defensible in five years".
- **Alpine release cadence gap** — no npm publish since 2026-04-30 despite 50 merged PRs in 2026. Worth one check in ~2 months: if the gap reaches 6 months again with merged work unreleased, that is a release-process bottleneck attributable to single-publisher risk (D4-9).
- **Vue funding depth** — the sponsor page routes to a personal GitHub Sponsors account and OpenCollective. Actual sums, and whether any core member is employed full-time to work on Vue, remain unverified and would sharpen the bus-factor claim.

## Looked for and could not find

- **Any Alpine governance document, team page, or list of people with commit access.** Bus factor for Alpine (D4-9) is inferred from commit authorship and PR-approval behaviour, not from a stated policy. No succession plan is published.
- **Confirmation of the awesomealpine 471.6 → 116.1 bytes/proxy figure at its source**, and any merged upstream Alpine PR implementing it (D4-24). Budget exhausted before I could read the post itself.
- **The publication date of `@vue/reactivity` 3.1.1.** I confirmed the pin string but did not fetch that package's own registry time map; "mid-2021" is carried from the brief and remains unverified this run.
- **Vue's organisational/funding structure beyond the sponsor page** — no foundation, no legal entity, no employment arrangement (e.g. any full-time sponsorship of core maintainers) confirmed from a primary source. The vuejs.org/about/team page is client-rendered and returned no data to WebFetch; the roster came from the docs repo JSON instead.
- **Alpine's issue-triage policy** that would explain 3 open issues on a 31.8k-star repo (D4-17). Not located; the low number is therefore reported with a caveat rather than as unqualified health.
